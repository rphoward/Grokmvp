# Context index (portable `Planner/` kit)

Greenfield read order for repositories that carry only this `Planner/` tree:

1. `Planner/router-state.md` — which run directory and `STATUS.md` are active.
2. The `STATUS.md` file named by `active_status` in that stub (default:
   `Planner/slice-runs/_template/STATUS.md`).
3. `Planner/AGENTS.md` — guardrails, write boundaries, verification habits.
4. `Planner/CONTEXT.md` — shared vocabulary for this kit (grill-resolved terms).
5. `Planner/contracts/README.md` — v4 contract stack and read order.
6. `Planner/context-index.md` — short index for this kit.
7. `Planner/phase-map/README.md` — phase map stub and validation gate (chat-only
   per `Planner/contracts/phase_map_review_prompt.md`).
8. `Planner/intake/SPEC-SEED-grokmvp.md` — source packet for this repo (or
   `SPEC-SEED.stub.md` when adopting the kit elsewhere).
