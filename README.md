# Grokmvp (factory)

This repository is the **factory**: one place for the whole works—Cursor agent rules (`.cursor/rules/`), the portable Planner kit (`Planner/`), human docs (`docs/`), machine records (`assets/`), and a reference product tree ([`Grokmvp/`](Grokmvp/) for dogfood and layout examples).

There is no separate product GitHub repo in this model. Develop and version everything here; copy `Planner/` or publish artifacts to other repos when a target project needs them (see `Planner/TARGET-REPO-LIFT.md`).
